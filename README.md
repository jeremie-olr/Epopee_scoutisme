# L'art de dire bonjour

Une page statique qui dit bonjour — et explique comment on le dit vraiment en France.

## Ce que fait la page

- La salutation suit l'heure réelle du visiteur : **Bonjour** le jour, **Bonsoir** à partir de 18 h, avec la note d'usage correspondante.
- Un sélecteur **vouvoiement / tutoiement** réécrit la phrase d'accueil.
- Trois colonnes d'usages : la règle du bonjour unique (et le « re »), le nombre de bises par région, la formule de départ selon l'heure.
- Conventions typographiques françaises respectées : heure écrite `14 h 32`, espaces fines insécables avant `?` et dans les guillemets.
- Thème clair (affiche imprimée) et thème sombre (plaque de rue émaillée), selon les préférences du système.

## Utilisation

Aucune dépendance, aucun build. Ouvrir [`index.html`](index.html) dans un navigateur.

Les polices (Bodoni Moda, Karla, IBM Plex Mono) sont chargées depuis Google Fonts ; hors ligne, la page retombe sur les polices système déclarées dans les piles de secours.

## Publication

Le fichier étant nommé `index.html` à la racine, le dépôt peut être servi tel quel par GitHub Pages : *Settings → Pages → Deploy from a branch → `main` / `root`*.
